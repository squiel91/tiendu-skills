# tiendu-headless

Agent skill for building a Tiendu storefront on your own hosting with the public Storefront model, SDK 2, embedded overlays, analytics and store Functions. The Storefront API is unreleased.

Start with [SKILL.md](./SKILL.md), then [the complete minimal site](./references/quickstart.md). Generated schema and SDK references match the theme skill and are checked for drift.
