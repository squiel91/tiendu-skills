# tiendu-headless

Agent skill for building a Tiendu storefront on your own hosting with the public Storefront model, SDK, embedded overlays, analytics and store Functions. The Storefront API is served on stores.tiendu.uy.

Start with [SKILL.md](./SKILL.md), then [the complete minimal site](./references/quickstart.md). Use `tiendu-store-api` for the shared generated schema, SDK reference and shopper concepts.
