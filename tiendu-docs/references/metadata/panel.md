# Metadata in the Merchant Center

- **Store metadata**: **Ajustes → Tienda → Desarrollo y API**, section **Metadatos** ("Agregá campos personalizados que pueden ser usados para modificar la experiencia en tu tienda"), with **Agregar metadatos**. Some options are visible only with **Modo desarrollador** enabled.
- **Product metadata**: in a product, **Editar metadatos** (it shows **Metadatos agregados** once values exist). It appears only if the store defines `--detailed-product-metadata` with a schema.
