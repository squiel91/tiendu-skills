# Metadata in the Merchant Center

> [!WARNING]
> Metadata is deprecated. Use the store [SQLite database](../store-database/overview.md) for new data.

- **Store metadata**: **Ajustes → Tienda → Desarrollo y API**, section **Metadatos** ("Campos personalizados para tu tienda. Para guardar datos nuevos, usá la base de datos de esta página."), with **Agregar metadatos**. The section title shows a **Deprecado** label.
- **Product metadata**: in a product, **Editar metadatos** (it shows **Metadatos agregados** once values exist). It appears only if the store defines `--detailed-product-metadata` with a schema.
