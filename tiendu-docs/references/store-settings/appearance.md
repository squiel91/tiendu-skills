# Checkout and email look

**Ajustes → Tienda → Personalización** controls the parts of the storefront that are not theme code: the cart, checkout, shopper account overlay and shopper emails. It is independent of the theme.

| Setting | Effect |
|---|---|
| **Color principal** | Buttons, links and selection. |
| **Color de boton primario** | Text color of primary buttons only. |
| **Tipografía** | A Google font for checkout and account screens. Emails never use it: they use a safe system font stack. |
| Rounding | From **Sin redondeo** to **Muy redondeado**, for controls and panels. |
| **Logo del negocio** | Header of order, subscription and account emails; the store name is used when empty. |
| **Imagen de acceso** | Image on the left of the **Acceder** overlay on tablet and desktop. |

The page previews the checkout and the order email. Emails follow the same colors and rounding, are sent as `{Store name} <{storeHandle}@tiendu.uy>` and carry no Tiendu branding.

The theme's own colors and fonts are changed in the customizer or in theme code, not here.
