# URL rules in the Merchant Center

**Ajustes → Negocio → General** (`/admin/tiendas/{storeHandle}/ajustes/negocios`), section **Redirecciones y Reescrituras**: "Redirigí enlaces o mostrales otro destino manteniendo la URL en el navegador."

- **Agregar regla** opens the form; clicking a row edits or deletes it. The list can be searched by **Desde** or **Hacia**.
- Fields: **Acción** (Redirección (301) or Reescritura), **Coincidencia exacta**, **Desde**, **Hacia**.
- For a prefix rule, write `/prendas` and uncheck **Coincidencia exacta**.
