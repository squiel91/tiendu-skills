# tiendu-theme

Agent skill for changing a Tiendu storefront theme: folder routes, layouts, GraphQL data files, snippets, assets, `routes.json` URLs, the client SDK, push validation, and the Git workflow for previews and publishing.

```bash
npx skills add https://github.com/squiel91/tiendu-skills --skill tiendu-theme
```

Start with [SKILL.md](./SKILL.md) for the rules and the map of references.
